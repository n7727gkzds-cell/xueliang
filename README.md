## 一、怎么跑起来（三种方式，任选）

| 方式 | 操作 | 说明 |
|---|---|---|
| **A. 零依赖直接看** | 双击 `index.html` | 游客模式：本地规则引擎，秒出应用。无登录、无云端保存 |
| **B. 完整体验（推荐）** | `npm start` | 启动本地服务，带注册登录、云端保存、真实发布地址；默认端口 8137，被占用时自动顺延并打印真实地址 |
| **C. 手动指定端口** | `PORT=8145 node server.js` | 同上；端口被占用时也可手动指定 |

> 本仓库是**纯源码目录**，根目录即代码所在（`index.html` / `app.js` / `engine.js` / `server.js` / `styles.css`），Node ≥ 18 即可运行，无第三方依赖，不需要 `npm install`。带 `一键启动.bat` 的完整提交包请用在线链接体验。
> 登录 / 云端保存 / 真实发布地址都需要本地服务（方式 B 或 C）；双击直接打开 HTML 时会自动降级为游客模式（file:// 下仍可注册本机账号使用）。
> 云端模型调用同样需要本地代理（浏览器不允许直连大模型 API，故由 `server.js` 转发）。

## 三·五、账号、持久化与发布

**注册登录**
- 邮箱 + 密码注册，密码用 scrypt 加盐哈希存，不存在明文；登录态是 HttpOnly 的 cookie
- 测试账号 `demo@forge.app` / `demo1234`，登录页有「一键填入」
- 不登录也能用：游客模式，数据留在浏览器里，不写服务端

**数据持久化（两层）**
- 登录后：项目简报、每个版本的完整代码、发布记录存在服务端（每用户一个 JSON 文件）。换台电脑、换个浏览器登录，项目照样在
- 未登录：退回 localStorage，关掉浏览器再回来也能恢复
- 顶栏头像里能看到同步状态：已同步 / 正在同步 / 同步失败

**发布**
- 发布生成**真实可访问**的地址 `/p/<slug>`，任何人打开都能查看并试用（不再是本地快照）
- 再点一次发布 = 更新线上版本，地址不变
- 版本历史里能看到哪一版在线上

## 四、功能清单

**智能体与生成**
- 四智能体流式协作，逐步展示思考过程（推理模型会实时滚动显示它的思考内容）
- 可接**真实大模型**（OpenAI 兼容协议）：已预置 **小米 MiMo `mimo-v2.6-flash`**，也支持 DeepSeek / OpenAI / 通义千问 / 智谱 / Kimi / 自定义端点
- 没配密钥或调用失败 → 自动回退本地规则引擎（8 类应用模板：作品集/咖啡馆/落地页/看板/活动/博客/工具/店铺 + 9 套配色），Demo 永不崩
- 支持中断（生成中点击发送按钮）、超时保护、图片设计参考（多模态）

**交互与工程**
- 响应式三档断点：窄窗口（≤1080）侧栏收窄；平板竖屏（≤880）上下分栏；手机（≤620）对话/预览全屏切换（底部悬浮切换条，生成完成后自动切到预览），登录页铺满全屏
- 实时预览（代码边生成边渲染）、设备框切换
- 代码面板三个模式：**查看**（语法高亮 + 流式流入）、**编辑**（直接改代码，应用后存为新版本）、**对比**（任意两个版本的行级 diff，标注新增/删除行数）
- 版本历史：回滚到任意一版、给版本改名、版本间对比
- 每个智能体带**可展开的产出物**：需求拆解 / 设计规格 / 构建结果 / 自检报告，并显示耗时
- 迭代会真的产生变化：本地引擎能响应「让营业时间更醒目好找」「文案再短一些」这类意见，并说明改了哪几处
- 项目简报 + 设计参考附件、发布/更新线上版本、下载 HTML
- 深浅主题切换、持久化（登录走服务端，未登录走本地）
- 预览导航守卫：生成页面里的空链接/相对路径/锚点不会把预览跳回 Forge 自身

## 五、技术架构

```
浏览器（纯静态）
├─ index.html / styles.css      三区工作台 UI
├─ engine.js                    本地规则引擎（意图解析 / 8 类模板 / 配色系统 / 兜底生成）
├─ app.js                       智能体叙述、流式生成、版本、发布、附件、模型设置
└─ server.js（Node，仅云端需要）  静态托管 + /api/llm 代理转发（SSE 流式，密钥不落服务端）
                                       ↓ OpenAI 兼容协议
                                 小米 MiMo / DeepSeek / Qwen / GLM / Kimi ...
```

- **零外部依赖**：不引用任何 CDN、字体或框架，离线可跑
- **密钥安全**：API Key 只存在浏览器 localStorage，代理转发时随请求发出，不写入服务端磁盘
- **分层可扩展**：模板/配色/意图规则都是数据表式组织，加类型 = 加一条配置

## 六、5 分钟演示脚本（建议照此走查）

1. 打开应用 → 看首屏引导与示例卡片
2. 点「☕ 社区咖啡馆」示例卡（或自己输入一句需求）
3. 观察左栏：🧭 规划 → 🎨 设计 → ⚙️ 构建 → 🔍 评审 逐步流出的思考过程
4. 右侧预览随代码流出**边生成边成形**；切换到 📱 手机框检查响应式
5. 点一条**改进建议**（如"让营业时间更醒目好找"）→ 生成 v2 → 点 🌐 发布拿网址 → 再点一次发布看"更新线上版本" → 打开 🕘 版本历史回滚对比

> 附：`示例产出-社区咖啡馆.html` 是本地引擎生成的成品样例，可直接双击打开查看质量；`演示截图.png` 是完整工作台截图。

## 七、已知限制与后续规划

| 限制 | 后续规划 |
|---|---|
| 产物是单文件 HTML，在线编辑是"整份改" | 拆成多文件结构，编辑粒度降到组件级 |
| 账号与状态用 JSON 文件存，够用但不正规 | 换数据库，补邮箱验证、找回密码 |
| 发布页无权限控制，拿到链接的人都能看 | 加私有链接、有效期、访问统计 |
| 推理模型（如 MiMo）生成较慢，约 1–3 分钟 | 已用"流式实时预览"缓解；可切换非推理模型提速 |
| 智能体叙述为编排式呈现 | 接入真实 Agent 框架，让规划/构建/评审真正分工调用工具 |
